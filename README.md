# Hi, I'm Zhifei Song

Postgraduate student at Nanyang Technological University, Singapore. I build macOS utilities, real-time video tools, and computer vision experiments.

## Featured projects

### [MagicKey](https://github.com/XiaoSong1223/MagicKey)

A macOS menu bar app that brings breathing, keystroke pulses, and music-reactive lighting to the built-in MacBook keyboard. Built with Swift, SwiftUI, and AppKit.

[Download](https://github.com/XiaoSong1223/MagicKey/releases/latest) · [English](https://github.com/XiaoSong1223/MagicKey#readme) · [简体中文](https://github.com/XiaoSong1223/MagicKey/blob/main/README.zh-CN.md)

### [WebRTC Virtual Background](https://github.com/XiaoSong1223/webrtc-virtual-background)

Browser-side person segmentation and background compositing with MediaPipe, WebGL2, and Web Workers. A reusable video-processing pipeline connected to LiveKit, with a standalone preview and evaluation tools.

[Engineering report](https://xiaosong1223.github.io/webrtc-virtual-background/report.html)

### [SimSiam-YOLO](https://github.com/XiaoSong1223/SimSiam-YOLO)

Feature-level SimSiam pre-training and progressive fine-tuning for YOLOv8 traffic sign detection with limited labeled TT-100K data. Includes the thesis, experiment configurations, and result figures.

### [DSH Release Guardian](https://github.com/XiaoSong1223/dsh-release-guardian)

Local, deterministic release-risk checks for Git changes, available through DeepSeek Harness, a standalone CLI, and optional coding-agent adapters.

### [Hypergraph-YOLOv9-MultiScale](https://github.com/XiaoSong1223/Hypergraph-YOLOv9-MultiScale)

A multi-scale convolution detection head for Hyper-YOLO / YOLOv9, explored on tomato ripeness detection.
